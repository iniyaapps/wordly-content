Wordly content 🌎

Public game content for the Wordly Android app.

This site serves static JSON read by the app. There is no API and no server — just files.

  • version.json — content and per-language versions
  • languages.json — the language catalogue
  • categories.json — shared category keys
  • languages/<code>/ — metadata, words, categories, puzzles

No user data is collected or stored here. Player progress stays on the player's device.
